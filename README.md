# First Chorus

**はじめてのジャズアドリブ**
*Your First Step Into Jazz Improvisation*

First Chorusは、楽器を演奏でき、楽譜も読める人が、コード進行を理解しながら、**自分でジャズのアドリブを作る**ための練習アプリです。

コードトーン、ガイドトーン、ターゲットノート、アプローチノート、リズム、モチーフなどを段階的に学び、「コードを確認 → 使える音とルールを確認 → 伴奏に合わせて自分で演奏 → 自己評価」のサイクルで、自分のフレーズを作る力を身につけることを目指します。

公開URL: https://tanbo-hiroooi.github.io/Jazz-improvisation/

## 想定ユーザー

- 楽器の演奏経験がある(吹奏楽・クラシック・ポップスなど)
- 五線譜が読める
- アドリブは初心者
- スケールは分かるが、フレーズにできない
- コード進行に合わせた音選びを学びたい

## 2つの主要モード

### 自由練習
苦手な技術を自分で選び、反復練習するモード。画面上部の「やること」タブで**♪ 基礎練習**(コードトーン/ガイドトーン/アプローチ/ターゲット/スケールの表示を切り替え、11種のリズムパターンと組み合わせる)と**🎼 フレーズを作る**(拍グリッドで自作する。小節数は進行に合わせて1〜12小節から選択)を切り替えます。

### 練習コース
理論の暗記からではなく、**リズム→音選び→置く拍→つなぐ→語る→1コーラス**の順で学ぶ「リズムから始めるアドリブ入門」(全6章・27レッスン)を収録。基本ルールは「一度に変えるものは1つだけ」です。

## 練習コースの特徴

章構成: ①1音とリズムだけでスウィングする → ②コードの中から使う音を選ぶ → ③拍の頭と裏を使い分けて音を置く → ④コードが変わる小節間を半音で繋げる → ⑤同じ形を繰り返して1コーラスにする → ⑥ブルースで1コーラスのソロを作る

第2〜5章の最後は**【通し】レッスン**で、その章の技だけを使って12小節ブルースを1コーラス作ります。同じ形が毎章戻ってくるので「何のために練習しているか」が体験で分かり、4小節から12小節への段差もなくなります。

第3章は ii-V-I の役割とリズムを結びつける章です。落ち着かない場所(Dm7)は裏拍から入り、G7から次の小節へ食い込み、落ち着く場所(Cmaj7)の1拍目で着地する — 同じ音でも置く拍を変えるだけで聞こえ方が変わることを、自分でA/B両方を作って聴き比べます。

レッスンの文章は「**できること**(成果)」と「**やること**(1行の作業指示)」の2本立てで、指示は「〜しよう」で終わります。理由や背景は折りたたみの豆知識に収納しています。タイトルは動作形で、専門用語はサブ表示に逃がしています。

各レッスンは3区分のシンプルな構成です。

1. **このレッスンでできるようになること** — 練習後の変化が一文で示される
2. **STEP** — 小さなSTEPを1つずつ表示。各STEPが専用の楽譜・ルール・課題を持ち、編集が必要なSTEPには拍グリッドエディタが埋め込まれています
3. **できたかチェック** — チェックボックス式の自己評価

補足(なぜ効くのか・よくある失敗)は折りたたみの「豆知識」に収納。編集STEPは条件と操作課題を満たすまで「次のSTEP」が有効にならず、全STEP完了で「レッスン完了」が解放されます。

**テンポ/キーのはしご**: 多くのレッスンに 60→70→80→100 BPM、C→F→B♭ のはしごが付いています。「クリアした!」で達成を記録し、自分のペースで上がります(進行の条件にはなりません)。メトロノームは**毎拍**と**2・4拍**(ジャズの定番)を切り替えられます。

**練習の長さ(4小節/8小節)**: ii-V-I の課題は「**練習の長さ**」で8小節に伸ばせます。8小節は進行を2回くり返すので、前半で問いかけて後半で答える形が作れます。音符数・休符の条件は長さに合わせて増え、説明文の数字もそれに追従します。長さを変えても作りかけは消えません(前半を残して後ろに空の小節が足されます)。

**章まとめ練習**: 各章の一覧の下にある「📝 この章をまとめて練習」から、**その章の課題を1つの譜面の上でまとめて**練習できます。章の各レッスンの条件が、いま作っているフレーズに対してリアルタイムで判定され、チェックリストとして並びます(例: 第1章は5レッスンぶんの条件が1つの4小節に同時に成立します)。レッスンを1つずつ進むのが「学ぶ」段階、この画面が「通して使う」段階です。

**譜面は1画面に収める**: 譜面は、割り当てられた高さに**全体が収まるように自動で組み直します**。小節数が多いときは1行あたりの小節数を増やして(必要なら少し縮小して)、演奏しながらスクロールしなくて済むようにします。例えば音を詰めた12小節は、以前は譜面の高さが1284pxになり730pxぶんスクロールが必要でしたが、いまは392pxに収まります(1行4小節×3行)。

**譜面全体で練習**: 「▶ 伴奏を流す」を押すと、譜面と再生ボタンを中心にした全画面表示へ切り替わります。音を出さずに準備する場合は、譜面の「⛶ 譜面全体で練習」から開けます。練習コース・章まとめ・自由練習の基礎練習とフレーズ作成すべてで使えます。譜面は実際の空きスペースに合わせて全小節が収まる大きさに調整され、スマートフォンの縦横切替にも追従します。「テンポ・再生設定」は必要なときだけ開けます。Escか「✕ 閉じる」で編集に戻り、作りかけとUndo履歴は保持されます。画面の小さい端末で音符が細かく感じる場合は、横向き表示も試してください。

**Practice with the full score**: Starting the backing opens a full-screen score in lessons, chapter workouts, fundamentals and the phrase editor. Use “Practice with full score” to open it before playing. All bars fit the available space, including after rotation or opening “Tempo & playback settings.” Close the view or press Esc to return to editing with your phrase and undo history intact. Try landscape orientation when notes look small on a phone.

## フレーズ作成(拍グリッドエディタ)

1小節=4拍の**固定の枠**をマスで埋める方式です。合計は構造上つねにぴったり4拍×小節数になるため、拍数の計算や「どこが超過しているか探し」は不要です。

**縦=音の高さ / 横=拍**の表になっていて、置きたい高さの行と鳴らしたい位置が交わるマスをタップすると、その音がそこに置かれます。

- 行に並ぶのは**そのコードで使える音だけ**(コードトーン/ガイドトーン/スケール/ブルース)。コードトーンの行には色が付き、Root/3rd/5th/♭7thの役割ラベルが出ます
- 音の高さを変える: 同じ位置の**別の行をタップ**。左の音名をタップすると、その音だけ鳴らして確かめられます(選択中は▲▼でも動かせます)
- 表示する音域は既定でG3〜D5。左上の▲▼で1オクターブずつずらせます(音が置いてある行は範囲外でも残ります)
- 音の長さ: **→のばす / ←縮める**。伸ばした音は同じ行の横棒としてつながって見えます。拍・小節線もまたげます(譜面はタイで表示)
- 拍ごとに分割を切替: **♩ / ♫ / ♫³ / ♬**(4分・8分・3連・16分)を音符の記号から選びます。レッスンごとに選べる分割が変わります
- キーボードでも操作できます: 矢印キーでマスを移動、Enter/Spaceで置く
- **アーティキュレーション**: 普通 / アクセント(>) / 短く(スタッカート) / 長く(テヌート)。譜面記号と再生(音量・音価)の両方に反映
- **⧉前の小節をコピー**: モチーフやリフを4小節・12小節へ一気に展開(音は各小節のコードの度数へ自動対応)
- 編集内容とUndo/Redo履歴はSTEPごとに保持。キー変更時は確認のうえ新しいキーで作り直します
- 小節数は課題に応じて4〜12小節。自由練習の「🎼 フレーズを作る」タブでも同じエディタを使えます(素材はグリッドのすぐ上で切替: コードトーン/ガイドトーン/スケール/ブルース。小節数は選択した進行の長さまで自由)

**「音を確認」は見本演奏ではありません。** ユーザー自身が編集した楽譜を、設定したBPMと正しい音程で再生して内容を確認するための機能です。

## 楽器選択の仕組み

- **マイ楽器(基本設定)**: ホーム画面で普段使う楽器・譜表・表示ピッチ・(ギターの)譜面表示を保存します
- **今回の練習設定**: レッスンを開いたときに、マイ楽器を初期値とした確認パネルが表示され、**今回だけ**別の楽器や譜面に変更できます(マイ楽器は自動では上書きされません)
- 「この設定をマイ楽器に保存」を選んだときだけ基本設定が更新されます
- **表示ピッチ(実音/記譜)**: 選択肢は、記譜で音名が変わる移調楽器(B♭管・E♭管)にだけ表示されます。ピアノ・トロンボーン・ボーカルは実音と記譜が同じ、ギター・ベースは慣習どおり常に実音の1オクターブ上に記譜するため、どちらも選択肢を出さずに理由だけを注記します(ギターのTAB譜は実音から算出するため影響を受けません)
- そのままでよければ「この内容で始める」1タップで練習を開始できます

## ギター対応(TAB譜)

Guitarを選ぶと、譜面表示を **五線譜 / TAB譜 / 五線譜+TAB**(初期値)から選べます。

- チューニング: Standard(E2 A2 D3 G3 B3 E4)※データとして管理、将来の拡張に対応
- ポジション: 自動 / オープン / 第3・5・7・9ポジション(指定範囲のフレットでTABを生成)
- 開放弦の使用: オン/オフ
- TAB生成は「指定ポジション内で、前の音から近い弦・フレットを選ぶ」方針。五線譜・再生音とTABの音程は常に一致します
- TABのみ表示でも、度数表示をオンにすると Root / 3rd / 7th などの役割ラベルがTAB上に表示されます
- ギターの五線譜は慣習どおり実音より1オクターブ上に記譜(Written選択時)

## 見本演奏を使用しない方針

現在のバージョンでは、**自動生成された見本演奏や見本フレーズは使用していません**。
使用する音、ターゲット、練習条件を確認し、ユーザー自身がフレーズを作ることを重視しています。

**この方針の境界(明文化)**:
- **OK**: メトロノーム/カウントイン/シンプルなコード伴奏/**譜面に表示された固定の教材譜例の再生**(「この音を確認」— リズムパターンやガイドトーンの道など、あらかじめ楽譜として提示されている内容)/**ユーザー自身が編集したフレーズの再生**(「音を確認」「コードと一緒に確認」)
- **NG**: AIや乱数による見本ソロ・見本フレーズの生成、その再生。「お手本を聴いてまねる」形の機能

つまり「譜面に見えているものを音にする」機能だけを持ち、「演奏のお手本」は提供しません。リズム中心の第1章でも、聴くのはすべて譜面どおりの固定譜例です。

## 対応機能

- 練習メニュー: ii–V–I / マイナーii–V–I / ジャズブルース / 循環進行 / 逆循環 / 枯葉進行 / マイナーブルース / 自分でコードを決める
- **自分でコードを決める**: 1〜16小節。コードタイプは12種類を系統別に選べます
  - メジャー系: maj7 / maj9 / 6
  - マイナー系: m7 / m9 / m6
  - ドミナント系: 7 / 9 / 7sus4 / 7(♭9)
  - その他: m7♭5 / dim7
- **1小節に2コード**: 各小節の「＋2拍」を押すと、1拍目と3拍目で別のコードにできます
- **入力する小節を譜面から選ぶ**: 「フレーズを作る」では最初は譜面だけを表示し、五線譜の小節をタップするとその小節の入力欄が現れます(前/次ボタンでも移動可)。12小節でも入力欄が縦に伸びません
- **譜面の見やすさ**: 譜面エリアは画面の高さいっぱいまで使い、広い画面では1行に最大6小節を並べます。音符の多い小節があるときは、音符が重ならないように1行の小節数を自動で減らします(最終行だけ1〜2小節にならないよう、8小節は4+4のように分けます)
- **フレーズの保存**: 「フレーズを作る」で作った譜面は名前を付けて保存できます。音符だけでなく進行・キー・使う音・小節数もまとめて保存するので、読み込むと作ったときの状態がそのまま戻ります(ブラウザに保存・最大50件)
- キー変更(12キー、全表示が自動移調)
- BPM設定(40〜220、再生中もライブ反映)
- メトロノーム(毎拍 / 2・4拍) / 4カウントイン / ループ(全体・2小節・1小節)/ 簡易コード伴奏
- スウィング再生(なし/軽め/標準/強め。16分はイーブン)
- 五線譜表示(VexFlow): 再生位置ハイライト、3連符対応、音名・ドレミ・度数の補助表示
- コード情報(コードトーン・ガイドトーン・おすすめスケール・テンション・度数)
- 楽器設定: Piano / Guitar / Bass / Trumpet / Trombone / Soprano・Alto・Tenor・Baritone Sax / Vocal / Other
- 移調楽器対応(Concert / Written 切替。B♭管・E♭管の記譜表示、ギターの記譜オクターブ)
- ギターTAB譜(下記参照)
- 練習コースの進捗保存・自己評価(localStorage)
- 練習ログ(日時・メニュー・キー・BPM・楽器・練習内容・メモ)
- 表示言語: 日本語 / English

※録音機能は未実装です(今後の方向性を参照)。

## 技術構成

- React 18 + TypeScript 5 + Vite 5
- Tone.js 15(メトロノーム・伴奏などの音声再生)
- VexFlow 4(五線譜レンダリング)
- データ保存: localStorage(保存層は `src/state/storage.ts` に抽象化)

```
src/
├── theory/       # 音楽理論ロジック(音名・コード・進行・移調・ノート生成)
├── audio/        # Tone.js 再生エンジン
├── data/         # 練習コンテンツ(コース・レッスン)※UIから分離
├── hooks/        # usePracticePlayback(再生制御の共有フック)
├── screens/      # ホーム / 自由練習 / 練習コース
├── components/   # 五線譜・進行表示・コード情報・練習ログ
├── state/        # 進捗保存の抽象化
└── i18n.ts       # 日英表示文字列
```

## ローカルでの起動方法

```bash
git clone https://github.com/Tanbo-hiroooi/Jazz-improvisation.git
cd Jazz-improvisation
npm install
npm run dev      # http://localhost:5173
```

## ビルド

```bash
npm run build      # 型チェック + 本番ビルド(dist/ に出力)
npm run preview    # 本番ビルドの確認
npm run typecheck  # 型チェックのみ
```

## デプロイ

`main` ブランチへの push で、GitHub Actions([.github/workflows/deploy.yml](.github/workflows/deploy.yml))が自動でビルドし GitHub Pages へデプロイします。手動実行も Actions タブの「Run workflow」から可能です。

## iOSでの利用について

- 音は最初のタップ(Startなど)で有効になります(AudioContextの制約に対応済み)
- マナーモード(無音スイッチ)ONだと音が出ないことがあります
- 将来的なiOSアプリ化は、ロジック層とUI層を分離した現構成のままCapacitorでラップする経路を想定しています
